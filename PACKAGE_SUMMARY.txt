SETUP INSTRUCTIONS
------------------
1. Extract the zip file
2. Navigate to the extracted directory
3. Create a virtual environment:
   python3 -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
4. Install dependencies:
   pip install -r requirements.txt
5. Verify installation:
   python scripts/parse_stig.py --help

QUICK START
-----------
See README.md in the package for detailed instructions.

The main workflow is:
1. Parse STIG XML: python scripts/parse_stig.py --xccdf <file> --output <json>
2. Generate hardening: python scripts/generate_hardening.py --input <json> --output <yml> --product <product>
3. Generate checker: python scripts/generate_checker.py --input <json> --output <yml> --product <product>
4. Generate CTP: python scripts/generate_ctp.py --input <json> --output <csv> --manual-only
